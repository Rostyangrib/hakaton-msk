# Запуск для предзащиты

Из папки репозитория:

```powershell
$env:PYTHONIOENCODING='utf-8'
python tools/demo.py
```

Демонстрация занимает несколько секунд. Она запускает реальный Controller на справочниках кейса и явно синтетических наблюдениях: обычное движение, подтверждённое закрытие впереди с полным объездом и затор с LIMIT_SPEED 30. Каждый полный ответ проходит JSON Schema и независимый контроль маршрутов/ресурсов. Затем проверяются граница маршрутного выбора и совместное назначение ресурсов. Полные ответы сохраняются в `results/demo` вне Git. Скрипт завершится ошибкой, если ожидаемое поведение нарушено.

Регрессионные проверки:

```powershell
$env:CORRIDOR_REFERENCE="$PWD/reference"
python -m unittest discover -s tests -v
```

Короткое объяснение: «Программа получает пакет наблюдений, обновляет причинную историю и формирует полный JSON. Мы проверяем направленный граф, массу и ODD, сравниваем статический и динамический путь по согласованному правилу, совместно распределяем площадки и операторов. Перед выдачей ответ независимо проверяется. Данные и рекомендации разделены: команда не считается исполненной».

На защите следует говорить о доказанной корректности интерфейса, проверках алгоритмов и соблюдении проверяемых ограничений. Качество диагностики и ODD на сложных данных неоднородно; полный анализ ещё выполняется. Не следует называть confidence откалиброванной вероятностью или обещать гарантированную физическую безопасность.
