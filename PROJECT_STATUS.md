# Статус проекта

Этапы 0–3: выполнены и проверены. Этапы 4–12: ожидают реализации.

Следующий шаг: базовые оценки дорог и простая политика действий.

Ограничения: неизвестные правила полезности/переключений, пространственная семантика погоды, физическая допустимость последнего HOLD, семантика поддержки. Runtime выдаёт технические UNKNOWN/HOLD; алгоритм движения ещё не реализован. Docker и полные контрольные прогоны не выполнены.
