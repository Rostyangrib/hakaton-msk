# Анализ PUBLIC-рекомендаций

`PUBLIC_ACTION_DISTRIBUTION.ipynb` анализирует сохранённые ответы Docker-образа, без labels и повторного запуска алгоритма. В Git хранится исходный notebook без выходов ячеек. Выполненная локальная копия с таблицами и пятью графиками: `../../output/analysis/PUBLIC_ACTION_DISTRIBUTION.ipynb`.

По умолчанию используются `results/technical-submission/PUBLIC-101.ndjson.gz` и `PUBLIC-102.ndjson.gz`. Также поддерживаются имена `PUBLIC-*.result.ndjson.gz`. Папку можно изменить в конфигурационной ячейке либо через переменную окружения `CORRIDOR_RESULTS_DIR`. Сами файлы результатов в Git не включаются. При наличии архива `Кариков Team.zip` рядом с репозиторием проверяется совпадение PUBLIC-файлов по SHA256.

Зависимости для интерактивного запуска: `python -m pip install pandas matplotlib jupyter`. Затем откройте notebook в Jupyter или VS Code и выполните все ячейки. При запуске выполненной копии из `output/analysis` соседний репозиторий `hakaton-msk` обнаруживается автоматически. Для просмотра сохранённых таблиц и графиков повторное выполнение не требуется.

Считаются рекомендации на пару «автомобиль — пакет», а не выполненные манёвры. Один автомобиль может получить одинаковую рекомендацию много раз. Поддержка — флаг назначения текущего снимка. Частоты действий и собственные оценки ODD не доказывают физическую безопасность или истинную правильность решений.
